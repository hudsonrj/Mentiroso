# O Mentiroso

Site estático de crítica política ao governo Lula: promessas de campanha, custos, dívida, programas sociais, educação, saúde, gastos com cartão corporativo e viagens, segurança pública e eleição.

Para ver o site, abra o `index.html` no navegador. Também dá para publicá-lo de graça pelo GitHub Pages (Settings → Pages → escolha a branch e a pasta raiz).

- `index.html`: estrutura e textos de cada seção
- `app.js`: dados (promessas, tabelas, gráficos e fontes) e renderização
- `styles.css`: visual

Os dados vêm de órgãos públicos (BC, IBGE, MDS, Ministério da Saúde, TSE, TCU e Portal da Transparência) e da imprensa. As fontes estão listadas no fim da página. Os números mudam com frequência; para atualizá-los, edite os arrays em `app.js`.
